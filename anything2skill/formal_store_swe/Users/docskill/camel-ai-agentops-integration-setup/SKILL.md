# Camel AI AgentOps Integration Setup

Canonical skill for setting up AgentOps observability with Camel AI agents. Provides reference materials, integration patterns, and setup procedures to enable full agent tracking and analysis.

## Prompt

Access official Camel AI documentation, AgentOps integration examples, and agent tracking cookbooks. Use these resources to understand integration patterns, setup procedures, and troubleshooting guidance for AgentOps with Camel AI agents.

## Objective

Provide integration guidance and reference materials for Camel AI and AgentOps observability setup
## Applicable Signals

- Integration planning phase initiated
- Camel AI framework selected for multi-agent system
- AgentOps observability setup required

## Contraindications

- Integration is already complete and operational
- Only runtime execution support is needed without setup context

## Constraints

- Reference materials assume developer familiarity with agent frameworks
- AGENTOPS_API_KEY environment variable must be set before implementation

## Output Contract

- Developer has access to official Camel AI documentation, AgentOps integration examples, and agent tracking cookbooks; can proceed with integration implementation.

- Developer needs to understand Camel AI integration patterns
