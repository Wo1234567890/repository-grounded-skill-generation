# D3 Shape and Geometry Rendering

Select and configure a D3 shape generator (arc, area, line, pie, stack, symbol, or radial variant) to render geometric primitives from data, then bind the generated SVG path data or attributes to DOM elements to produce visual marks.

## Prompt

1. Identify the data structure and desired visual mark type (line, area, bar, pie, arc, symbol, or radial variant).
2. Select the appropriate D3 shape generator from d3-shape (e.g., d3.line(), d3.area(), d3.pie(), d3.arc(), d3.stack(), d3.symbol()).
3. Configure the generator with accessor functions to map data fields to geometric properties (x, y, radius, etc.).
4. Apply the generator to your data to produce SVG path data or geometric attributes.
5. Bind the output to SVG elements (path, circle, rect, etc.) via d3-selection.
6. Verify that the rendered marks match the intended visual representation.

## Objective

Generate SVG path data or geometric attributes for visual marks from structured data using D3 shape generators
## Applicable Signals

- Data is structured and ready for visualization
- Visual mark type has been selected
- SVG container and selection context are available

## Contraindications

- Only updating existing element attributes without changing shape type
- Working with pre-rendered static SVG that does not require data binding
- Data is not yet cleaned or structured

## Constraints

- Shape generator must receive data in the expected format (array of objects or primitives)
- Accessor functions must correctly map data fields to geometric properties
- SVG container must exist before binding elements

## Cautions

- Radial variants (radial areas, radial lines, radial links) require angle and radius accessors instead of x and y
- Stack generators modify data structure; ensure downstream operations account for stacked values
- Curve interpolation affects line and area smoothness; choose appropriate curve type for your data

## Output Contract

- SVG path data or element attributes generated by the shape generator and successfully bound to DOM elements, producing the intended visual mark (line, area, pie, arc, stack, symbol, or radial variant) that accurately represents the input data.
