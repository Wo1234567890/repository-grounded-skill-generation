# Schedule and Control Element Transitions 子技能地图

- [Query and Inspect Active Transitions](通用技能领域/Family技能/未分类技能/微技能/Query and Inspect Active Transitions/SKILL.md) ｜ 微技能
  - 适用：Retrieve metadata and state information about active or completed transitions, including selection references, element counts, and active transition handles. This is a read-only inspection skill that does not modify transition behavior.
  - 线索：Need to check if a transition is currently active on a node, Need to retrieve the selection associated with a transition, Need to count the number of elements affected by a transition, Need to access the first element in a transition, Need to verify if a transition is empty
