# D3 Axis API Reference Lookup

Canonical reference for D3 axis module API surface. Provides method signatures, orientation constructors, scale binding, and tick/format customization options. Used during axis implementation design to recall available methods and their purposes.

## Prompt

Use this reference to recall D3 axis method names, signatures, and available configuration options. Covers axis generators (top, right, bottom, left), scale binding, tick customization, formatting, sizing, and padding.

## Objective

Provide lookup and method signature reference for D3 axis API
## Applicable Signals

- Developer needs to recall axis method names or signatures
- Implementation requires axis configuration option lookup
- Axis orientation or tick customization decision point

## Contraindications

- Seeking conceptual guidance on axis design principles
- Looking for non-D3 axis solutions or alternatives
- Implementation is already complete and no reference needed

## Constraints

- Reference-only asset; does not execute axis generation logic
- Covers D3 axis module API surface only

## Cautions

- This is a lookup reference, not a workflow or execution guide
- For actual axis generation, pair with a session_skill that applies these methods

## Output Contract

- Quick reference lookup of available axis methods, their purposes, and configuration parameters

## Triggers

- Developer needs to recall axis method names, signatures, or available configuration options during implementation
